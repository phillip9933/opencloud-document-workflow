# 0.20.0 Beta

A local publication candidate consolidating the document workflow and recent reliability work. This version advances the existing 0.19.x series; it is not a stable or certified release.

- Processing settings offer Review first and Fully automatic with clear, meaningful step controls. One tag selector covers rules and optional AI tag discovery.
- Turning AI off preserves local text extraction, Tesseract OCR, custom-field label rules and tag matching. Only AI-dependent suggestions are disabled. Rules-only results require manual filing details and explicit acceptance.
- Activity combines processing and batch history, with selectable past imports, per-document recorded attempts and guarded reprocessing. Filing history remains a separate tab.
- Verified tag and field changes update the open document and library row in place instead of reloading the entire library.
- Document browsing supports list/folder views, contextual filters and inline details. Manually stored native files remain native; PDF conversion is explicit.
- Review has separate fields, tags and filing sections, folder/tag pickers, draft folder creation, sequential navigation and clearer Accept/Reject actions.
- Stable OpenCloud resource identity keeps tags, fields and historical records attached after external renames and folder moves inside the configured filing root. Cross-Space transfers remain outside that scope.
- Background processing uses existing OpenCloud App Tokens without depending on an open browser session. Backups and OCR language management are configurable.
- English, Japanese, Spanish, French and German interfaces, light/dark/system appearance and a visible beta version.
- Store packaging supplies a root-level manifest, matching installer bytes, corresponding source, checksums and fictional screenshots. Companion installation remains required.

Original bytes, current permissions, exact source identity, evidence checks and explicit approval/recovery guards remain enforced. Similar scans are warnings, not automatic duplicate deletion. CAD OCR still needs native PDF export; original-format manual filing is available. Cloud fallback and implicit conversion are not added.

See ../submission/VALIDATION.md for checks and ../docs/STORE_PACKAGING.md for the publication handoff. Hosted publication, new CI and public download checks are pending until explicitly performed.
